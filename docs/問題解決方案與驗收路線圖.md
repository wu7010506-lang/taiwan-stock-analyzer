# 台股研究台：問題解決方案與驗收路線圖

> 建立日期：2026-07-27  
> 原則：資料可信度優先於模型複雜度；所有推薦都必須揭露日期、缺漏與限制。

## 1. 資料可靠性

狀態：第一階段完成。

問題：公開資料源可能限流、延遲或部分失敗；同步完成不等於每檔股票皆為最新。

解決方案：建立資料品質中心，統一呈現各市場／資料集日期、覆蓋率、失敗批次與錯誤原因；失敗工作可重試，後續加入來源優先序與替代來源；推薦資格檢查必須拒絕過期或缺漏資料。

驗收：能從單一頁面找到每個資料集的最新日期與覆蓋率；同步失敗有股票、原因及建議處理方式；不完整股票不能進入正式 vNext 推薦。

已完成：新增「資料品質中心」、來源優先序與快取降級規則；覆蓋率只計目前股票清單中的不同股票，並依資料集容許日期差計算，避免超過 100% 或因日期不完全相同而誤判。vNext 繼續以新鮮度與完整度作硬門檻。

## 2. 推薦模型驗證

狀態：驗證框架完成，等待自然累積更多樣本。

問題：模型架構有研究依據，但權重、分數門檻、現金比例及集中度上限尚未由台股長期資料校準。

解決方案：增加因子單獨績效、分位數報酬、命中率、Information Coefficient、權重敏感度及市場狀態分組；保存每次模型版本與參數，禁止用同一樣本反覆挑選最佳參數後宣稱樣本外有效。

驗收：模型成績頁可比較因子與模型版本；至少報告多頭、空頭、盤整、過熱期間；人工門檻清楚標示為設計參數。

已完成：模型成績頁新增因子 Rank IC、高低分位報酬差、市場狀態分組、目前權重及逐因子加權敏感度。未達最低成熟樣本時只顯示進度，不允許自動調權。

## 3. 回測偏差

狀態：第一階段完成，歷史下市宇宙仍待外部資料。

問題：目前未完整處理股票股利、減資、拆股、下市櫃、停牌、漲跌停、存活者偏誤與市場衝擊。

解決方案：建立公司行動事件層與可交易性檢查；優先補上調整股數／價格與無法成交規則；回測輸出逐項揭露尚未處理的偏差，並擴大樣本外期間。

驗收：回測可區分價格報酬與總報酬；無法成交日不假設成交；結果包含成本、最大回撤、相對指數與限制清單。

已完成：現金股利與股票股利納入持有期總報酬；最低成交額、固定滑價、成本及樣本外切分已存在；新增流動性排除、未成熟出場及存活者偏誤稽核。尚未完整處理減資、拆股、現金增資、停牌、下市與逐日歷史上市名單，結果會明確標示而不宣稱偏誤已消除。

## 4. 同步與營運可靠性

狀態：本機版完成；公開多執行個體部署尚未啟用。

問題：SQLite 與網站程序內排程適合本機，但多程序部署可能重複執行，長任務也缺少完整恢復能力。

解決方案：短期強化資料庫互斥、步驟執行紀錄、逾時 running 回收與冪等；公開部署階段改為 PostgreSQL 與獨立背景工作程序。

驗收：同一時間只能有一個全站同步；中斷後可辨認並恢復；每個步驟皆有開始、完成、錯誤與資料筆數。

已完成：資料庫互斥、逐步進度持久化、過期 running 回收、失敗步驟隔離、觀察股一次重試與每日 vNext 快照。PostgreSQL／獨立 worker 僅在再次公開部署時需要。

## 5. 每日投資決策介面

狀態：完成。

問題：市場、推薦、持股與提醒分散，使用者仍需自行拼湊每日行動。

解決方案：建立每日儀表板，整合市場狀態、建議現金、持股加減碼、觀察股進場、資料警告、產業集中度與變更條件。

驗收：首頁即可回答今天投入多少、哪些股票需處理、為何處理及哪些建議因資料不足不可使用。

已完成：新增「今日決策」頁，整合資料決策閘門、市場狀態、現金目標、持股、優先觀察股、正式候選與集中度／資料風險；內部代碼轉為中文，觀察清單只顯示優先前 8 檔。

## 6. 版本、測試與文件

狀態：測試與文件完成；本機 checkpoint 待使用者允許建立 commit。

問題：目前工作樹包含大量未提交變更；部分研究文件描述落後於現有回測功能。

解決方案：建立一鍵本機測試腳本；每個里程碑完成後更新規格與完成度；完整測試通過後建立本機 checkpoint，未經使用者要求不推送。

驗收：核心 API、同步、vNext、回測與頁面測試全部通過；文件與實作一致；能從 checkpoint 安全回復。
