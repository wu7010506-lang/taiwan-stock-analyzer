# 股票推薦與買賣建議：專業資料比對報告

> 研究日期：2026-07-26。此文件是模型設計的研究與稽核資料，不是投資建議，也不代表任何報酬保證。

## 範圍與結論

本次將目前的新版模型（企業品質、估值、均線／市場狀態進場時機、法人追價風險、現金與集中度限制、停損／目標價、短歷史觀察模型）與學術原始論文及監管機構投資人教育資料比對。

**結論：方向大致合理，但不能宣稱已被驗證為有效。** 現有的「品質＋估值」與「價值＋動能／風險覆蓋」架構符合成熟研究脈絡；集中度控制、以資料不足降低部位、以及在高風險市場降低曝險也符合風險管理原則。主要缺口是：目前台股版本尚未做避免前視偏誤的樣本外回測，市場分數與 20／60 日均線門檻、60% 現金目標、10% 單檔及 25% 產業上限仍是設計參數，而非由台股資料估計出的最佳數字。

## 現行邏輯與證據比對

| 系統目前作法 | 比對結果 | 專業資料與含義 |
| --- | --- | --- |
| 將 ROE、獲利率、自由現金流、負債與獲利持續性整合為企業品質，再與估值合成價值分數。 | 合理，但權重尚未在台股驗證。 | [Fama 與 French（1996）](https://doi.org/10.1111/j.1540-6261.1996.tb05202.x) 的因子研究說明橫斷面報酬不能只用單一市場 beta 解釋，並指出模型仍遺漏短期報酬延續；因此品質／價值與趨勢應分開檢驗，不能因為皆有分數就假定總分有效。 |
| 用估值與趨勢一起決定買入、加碼、持有或觀望。 | 有文獻支持「搭配」而非單押單一因子。 | [Asness、Moskowitz、Pedersen（2013）](https://doi.org/10.1111/jofi.12021) 發現多國與多資產的價值、動能報酬普遍存在，且兩者負相關；這支持把價值與動能當互補訊號，不支持只看近期漲幅。原文：[PDF](https://docs.lhpedersen.com/ValMomEverywhere.pdf)。 |
| 時機分數以市場狀態 60% 與個股相對 20／60 日均線 40% 組成。 | 概念合理，實作證據不足。 | [Jegadeesh 與 Titman（1993）](https://doi.org/10.1111/j.1540-6261.1993.tb04702.x) 發現 3–12 個月的相對動能有效，但後續會部分消退。因此 20／60 日均線可作交易風險訊號，卻不應被解讀成「上漲機率」；應加入 3–12 個月動能、波動、成交成本，並以台股樣本驗證。 |
| 市場偏空時提高現金目標至 60%，一般股票觀望；品質高且無追價風險者可小額分批。 | 比「所有股票都觀望」更符合風險預算觀念；但硬性市場擇時不可過度自信。 | [Daniel 與 Moskowitz（2016）](https://doi.org/10.1016/j.jfineco.2015.12.002) 發現動能崩盤與市場下跌後、高波動、反彈情境有關，條件式風險調整能改善動能策略。原文：[PDF](https://www.kentdaniel.net/papers/published/jfe_16.pdf)。但 [Liu、Tang、Zhou（2019）](https://ssrn.com/abstract=3283395) 警告常見波動擇時容易有前視偏誤，修正後未必優於市場。因此市場狀態宜調整「曝險與部位」，不是宣稱能預測指數方向。 |
| 高波動／過熱時降曝險，並以法人淨買超與短期大漲辨識追價風險。 | 前半部有較強支持；法人追價門檻仍屬待驗證假設。 | [Barroso 與 Santa-Clara（2015）](https://doi.org/10.1016/j.jfineco.2014.11.010) 發現動能風險有可預測的時間變動，風險管理能顯著降低動能崩盤；原文：[PDF](https://assets.super.so/e46b77e7-ee08-445e-b43f-4ffd88ae0a0e/files/2d050545-c67a-4955-bac7-cba45a3375ec.pdf)。現有「法人買超占成交量 15% 且五日漲 8%」只是合理的警示規則，尚無台股樣本證明該組合與門檻最佳。 |
| 單檔逾 10% 建議減碼、產業曝險控制、顯示現金目標。 | 原則一致；數字需依投資人風險承受度調整。 | [SEC 投資人指南](https://www.sec.gov/about/reports-publications/investorpubsassetallocationhtm) 說明資產配置與分散可減少投資組合波動與重大損失風險；[FINRA 集中度風險說明](https://www.finra.org/investors/insights/concentration-risk) 也指出單一證券、產業或市場區隔過度集中會放大損失。兩者都沒有規定通用的 10%／25% 門檻；這些應在使用者風險設定中可調整。 |
| 停損觸發即賣出；目標價達標即減碼。 | 可作風險控制提示，但不宜視為保證成交或單一賣出依據。 | [FINRA 停損單說明](https://www.finra.org/investors/insights/stop-orders-factors-consider-during-volatile-markets) 指出賣出停損被觸發後通常成為市價單，劇烈波動時實際成交價可能明顯低於停損價。系統應將停損顯示為「需檢視／執行風險控管」並揭露跳空與流動性風險，且賣出判斷宜同時檢查基本面、事件與部位。 |
| 五年完整財報／三年價格才用正式長期模型；資料較短者採低信心、最多 1% 的試單／觀察。 | 保守方向合理。 | [Ritter（1991）](https://doi.org/10.1111/j.1540-6261.1991.tb03743.x) 發現其研究樣本中的 IPO 發行公司，在上市後三年相對配對公司表現較弱。此結果不能直接推論台灣每一檔新股必然下跌，但支持「短營運／交易歷史不能當成已證明的長期品質，應降信心與限縮曝險」。 |

## 與專業原則不完全相符或尚未完成的部分

1. **未做台股可交易回測。** 目前分數與買賣規則沒有以「當時可得資料」逐期重建，尚未扣除手續費、交易稅、滑價、流動性限制、下市股票與停牌。這是能否稱為推薦模型的第一優先缺口。
2. **市場狀態過度集中於單一分數。** 目前市場分數直接影響時機與現金比例，但未拆出趨勢、已實現波動、估值、廣度／漲跌家數與流動性。研究可支持以風險狀態調整曝險，卻不足以支持以單一市場分數判斷大盤方向。
3. **動能時間尺度太短。** 僅用 20／60 日均線，比研究常見的 3–12 個月相對動能更短，容易受雜訊與頻繁交易影響；應額外追蹤換手率與實際成本。
4. **基本面可比性需要產業調整。** 金融業已特殊處理，但 PE、PB、殖利率與營運週期在不同產業的可比性仍有限；同業百分位與分產業門檻通常比全市場固定 8–30 倍 PE 更穩健。
5. **法人資料不能直接等同「炒作」。** 法人買賣超可作流量／擁擠警示，不能單獨推論操縱或因果；需要以公開資料做事件研究與台股歷史回測。

## 建議的驗證與改善優先順序

1. 建立月度或週度的 **walk-forward 回測**：每個評分日只讀該日以前資料，分別量測 1、3、6、12 個月報酬、最大回撤、波動、換手與交易成本後績效。
2. 對長期模型、短歷史模型、單純大盤／等權基準做比較；分別報告完整資料與短歷史股票，避免把較高風險的公司混入而美化結果。
3. 將市場覆蓋改成可檢驗的風險預算：以波動、回撤、趨勢、廣度等個別欄位呈現，讓現金目標由事前規則產生，並與固定配置基準比較。
4. 將停損由「自動賣出結論」調整為「觸發風險檢視」；在低流動性或大幅跳空時特別揭露可能的成交偏離。
5. 將 10% 單檔、25% 產業、1% 短歷史試單和現金比例做成使用者風險設定，預設保守值，但不可宣稱對所有人最佳。這也符合 [FINRA 資產配置與分散說明](https://www.finra.org/investors/investing/investing-basics/asset-allocation-diversification)：配置應取決於風險承受度與投資期間。

## 使用上的正確解讀

- 「買入／小額分批」是符合目前規則與風險上限的候選，不是預測必漲。
- 「觀望」可以代表市場風險覆蓋、估值／趨勢條件未同時滿足，或證據不足；應分開顯示原因。
- 「減碼／賣出」應優先被理解為部位、停損或風險控制提示，而不是對公司未來的確定判決。
- 在完成台股樣本外回測前，推薦頁最適合定位為研究與風險管理輔助工具。
