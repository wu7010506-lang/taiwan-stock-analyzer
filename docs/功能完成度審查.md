# 台股研究台功能完成度審查

> 審查日期：2026-07-27  
> 依據：[網站最終目標與功能規格.md](網站最終目標與功能規格.md)

## 已完成且已有程式驗證

| 項目 | 證據 |
|---|---|
| 個股研究 | 公司業務、K 線、技術、營收、估值、財報、股利、股東結構與法人資料均有 API／頁面。 |
| 選股、觀察清單與持股管理 | 所有股票、我的股票、提醒中心及持股決策 API 已實作。 |
| 多模型推薦 | 綜合多因子、既有研究型、長期品質及 vNext 可分開使用；vNext 正式推薦僅收錄資料資格 `eligible` 的公司。 |
| 市場風險控制 | 市場狀態、過熱、現金目標、單股／產業上限與法人追價風險已納入 vNext。 |
| 同步可追蹤性 | 每日同步、分市場覆蓋率、來源／快取標示、觀察股缺失資料、一次性重試、逐步紀錄與失敗摘要已實作。 |
| 收盤後排程 | 伺服器平日台北時間 15:10 後自動執行一次；手動與排程同步有執行中保護。 |
| 回測頁面 | 歷史選股、Walk-forward、市場現金策略、樣本外切分、交易成本、滑價、最低成交額、現金與股票股利、偏誤稽核已呈現。 |
| 模型驗證 | 因子 Rank IC、分位報酬差、權重敏感度與市場狀態分組已實作；樣本不足時不自動調權。 |
| 今日決策 | 市場、資料閘門、建議現金、持股／觀察股行動、正式候選與重要風險集中在單一頁面。 |

## 已知限制：不可視為完成

| 項目 | 為何尚未完成 | 後續驗證或實作 |
|---|---|---|
| 其他公司行動 | 現金與股票股利已計入；減資、拆股及現金增資尚未完整建模。 | 建立完整公司行動事件與調整股數／價格序列。 |
| 下市／下櫃與存活者偏誤 | 現有資料庫以目前可取得股票為主，歷史下市股票未完整納入。 | 建立歷史成分／下市清單並保留當時可投資宇宙。 |
| 真實成交衝擊 | 目前使用最低成交額與固定 bps 滑價，是保守代理而非委託簿模擬。 | 依成交額、部位比例與波動度建立動態滑價。 |
| 回測樣本長度 | 現有市場策略實測僅有 12 期、樣本外 4 期，不能下投資結論。 | 補齊更長歷史價格與財報後，做跨市場狀態的樣本外驗證。 |
| 多執行個體同步鎖 | SQLite 目前避免單一資料庫中的執行中重複任務，但多台部署需外部工作佇列／分散式鎖。 | 部署時改用單一排程 worker 或外部 scheduler。 |

## 下一個客觀完成門檻

在將回測結果作為模型有效性證據前，至少應達到：

1. 台股可投資宇宙的歷史資料涵蓋一個完整景氣循環，且包含下市事件。
2. 至少 36 個月的 Walk-forward 期數與 12 個月以上預先指定的樣本外期。
3. 以總報酬、成本、滑價與流動性限制重跑，並同時報告相對指數、最大回撤與不同市場狀態結果。
4. 對每個預先固定的模型設定，只查看一次樣本外結果；若調整設定，重新指定新的樣本外區間。
