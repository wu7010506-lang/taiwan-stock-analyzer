# 台股推薦模型計分邏輯

更新日期：2026-07-22
適用版本：`evidence-layered-v1`、`long-term-quality-v8`

> 本系統輸出的是研究優先順序，不是保證報酬的買賣指示。分數必須和資料覆蓋率、估值、風險及失效條件一起閱讀。

## 1. 現有模型總覽

系統目前保留六種判斷模式：

| 模式 | 用途 | 核心特色 |
|---|---|---|
| 研究型推薦（新版） | 中長期研究排序 | 多年品質、現金流、估值、風險及產業化判斷 |
| 綜合多因子 | 綜合近期機會 | 基本面、估值、營收、技術、法人與市場並重 |
| 長期優質企業 | 成熟大型企業 | 品質、規模、獲利持續性與估值 |
| 價值型 | 尋找低估股票 | 本益比、股價淨值比與財務安全 |
| 成長型 | 尋找快速成長股票 | 營收成長、技術趨勢與基本獲利能力 |
| 品質型 | 尋找高品質公司 | ROE、毛利率、負債與估值 |

## 2. 研究型推薦（新版）

### 2.1 總權重

| 構面 | 權重 |
|---|---:|
| 企業品質 | 30% |
| 現金流／資本品質 | 20% |
| 獲利持續性 | 15% |
| 估值 | 15% |
| 風險韌性 | 10% |
| 成長品質 | 5% |
| 市場配適 | 5% |
| 合計 | 100% |

基本總分：

```text
總分 = 企業品質×30%
     + 現金流品質×20%
     + 獲利持續性×15%
     + 估值×15%
     + 風險韌性×10%
     + 成長品質×5%
     + 市場配適×5%
```

各原始指標多數先轉為 0～100 的同產業百分位。同產業有效樣本少於 5 檔時，改用全市場百分位。低值較佳的負債率、估值倍數與波動指標會反向計分。

### 2.2 資料納入門檻

一般企業、半導體及景氣循環企業必須同時符合：

- 至少 5 個財政年度資料；
- 至少 4 個完整年度；
- 至少 12 期營業現金流。

金融業不使用一般企業的現金流門檻，但仍需：

- 至少 5 個財政年度；
- 至少 4 個完整年度。

不符合門檻的股票不進入研究型推薦排名，不以 50 分代替缺失資料。

### 2.3 財報資料口徑

FinMind／公開資訊觀測站資料的口徑分開處理：

- 營收、營業利益、淨利與 EPS：單季值，年度值為四季相加；
- 營業現金流、資本支出與自由現金流：年初累計值，年度值採第四季；
- 自由現金流：`營業現金流 − |資本支出|`；
- 財報投入歷史估值時，第一至第三季延後 45 日才視為可取得，第四季延後 90 日，降低未來資料偷看。

### 2.4 一般企業：企業品質 30%

```text
企業品質 = 多年 ROE 中位數百分位×40%
         + 多年營業利益率中位數百分位×25%
         + 營業利益率穩定度百分位×15%
         + 負債率安全度百分位×20%
```

穩定度以多年數值的變異程度衡量；變異越小，分數越高。

### 2.5 一般企業：現金流品質 20%

```text
現金流品質 = 自由現金流為正比例×40%
           + 現金獲利轉換率×30%
           + 多年自由現金流率百分位×30%
```

其中：

```text
現金獲利轉換率 = 營業現金流 ÷ 稅後淨利
自由現金流率   = 自由現金流 ÷ 營收
```

自由現金流為正比例由 40%～100% 線性映射至 0～100 分；現金獲利轉換率由 0.5～1.5 倍線性映射至 0～100 分，超出範圍會截斷。

### 2.6 獲利持續性 15%

```text
獲利持續性 = EPS 為正年度比例×35%
           + 淨利為正年度比例×30%
           + 最近五年配息持續性×20%
           + ROE 穩定度×15%
```

配息年度達 5 年時取得完整配息分數。

### 2.7 估值 15%

#### 歷史資料可靠時

至少需要 500 個有效交易日，約兩年以上行情。自身歷史估值分數為：

```text
自身歷史估值 = 本益比便宜百分位×40%
             + 股價淨值比便宜百分位×20%
             + 自由現金流殖利率百分位×25%
             + 盈餘殖利率百分位×15%
```

最終估值：

```text
估值 = 自身歷史估值×70% + 橫向估值×30%
```

#### 歷史資料不足時

只使用同產業／全市場橫向估值：

```text
橫向估值 = 本益比便宜百分位×55%
         + 股價淨值比便宜百分位×20%
         + 股息殖利率百分位×25%
```

本益比或股價淨值比小於等於零時視為無效，不會被當成便宜訊號。

### 2.8 風險韌性 10%

```text
風險韌性 = 負債率安全度×35%
         + 營業利益率穩定度×25%
         + ROE 穩定度×15%
         + 自由現金流持續性×25%
```

### 2.9 成長品質 5%

```text
成長品質 = 多年營收年複合成長率百分位×45%
         + 當年度累計營收成長百分位×20%
         + 自由現金流持續性×35%
```

若自由現金流為正的期間少於 50%，成長品質最高只能得到 45 分。這項限制避免營收暴增但無法產生現金的公司獲得過高評價。

### 2.10 市場配適 5%

市場分數來自證交所加權指數近期狀態。

- 市場分數低於 40：進入防守狀態；企業品質、現金流品質、風險韌性均須至少 50 分，否則排除；通過後總分再扣 5 分。
- 市場分數至少 60：若成長品質至少 65 且企業品質至少 50，總分加 2 分，上限 100。
- 其他情況：不額外加減分。

## 3. 產業專用模型

### 3.1 金融業（產業代碼 17）

金融業不使用一般企業的負債率與自由現金流標準。

企業品質：

```text
企業品質 = 多年 ROE×55% + ROE 穩定度×20% + 持續獲利×25%
```

資本與獲利品質（置於原「現金流品質」構面）：

```text
資本與獲利品質 = ROE 穩定度×40%
               + 持續獲利×35%
               + 配息持續性×25%
```

風險韌性：

```text
風險韌性 = ROE 穩定度×35%
         + 持續獲利×35%
         + 股東權益規模×30%
```

金融業成長品質目前暫設 50 分。未來應補入淨利差、逾放比、資本適足率與保險負債等專用資料。

### 3.2 半導體（產業代碼 24）

半導體屬資本密集產業，現金流品質調整為：

```text
現金流品質 = 自由現金流持續性×20%
           + 現金獲利轉換率×45%
           + 自由現金流率×35%
```

目的在降低合理擴產期間高資本支出的過度懲罰，但仍要求營運最終能轉換為現金。

### 3.3 景氣循環產業

目前包含塑化、玻璃、鋼鐵、營建、航運、油電燃氣與光電等產業。

同時符合以下條件時，標記景氣高峰風險：

- 當年度累計營收年增率大於 20%；
- 多年營收年複合成長率低於 8%；
- 多年營業利益率變異程度大於 20%。

觸發後：

- 成長品質最高 40 分；
- 總分扣 7 分；
- 顯示「需確認獲利不是一次性高點」失效條件。

## 4. 研究結論

| 最終分數 | 顯示結論 |
|---:|---|
| 75 分以上 | 優先研究 |
| 65～74.9 | 可進一步研究 |
| 55～64.9 | 觀察 |
| 55 分以下 | 暫不推薦 |

常見失效條件包括：

- 現金流品質低於 50；
- 風險韌性低於 50；
- 估值低於 30，缺乏安全邊際；
- 市場進入防守狀態；
- 景氣循環高峰風險。

## 5. 綜合多因子模型

| 構面 | 權重 |
|---|---:|
| 基本面品質 | 25% |
| 估值 | 20% |
| 技術動能 | 15% |
| 營收成長 | 15% |
| 法人籌碼 | 8% |
| 流動性 | 7% |
| 整體市場 | 7% |
| 時事／產業趨勢 | 3% |

各構面算法：

```text
基本面品質 = ROE 百分位×50% + 毛利率百分位×25% + 負債率安全度×25%
營收成長   = 月營收年增分數×50% + 累計營收年增分數×50%
估值       = 本益比便宜度×55% + 股價淨值比便宜度×20% + 股息殖利率×25%
```

技術動能平均考慮：

- 5 日價格動能；
- 是否站上 20 日均線；
- 距離 52 週高點的位置。

法人籌碼使用外資與投信淨買賣百分位；流動性使用成交金額百分位；市場使用加權指數狀態；時事使用 TWSE／TPEx 重大訊息的有限幅度文字調整。

## 6. 其他保留模型權重

### 6.1 長期優質企業

| 構面 | 權重 |
|---|---:|
| 基本面品質 | 30% |
| 規模與韌性 | 20% |
| 獲利持續性 | 15% |
| 估值 | 15% |
| 流動性 | 7% |
| 營收成長 | 5% |
| 技術 | 3% |
| 市場 | 3% |
| 法人 | 1% |
| 時事 | 1% |

規模與韌性為營收規模百分位 60% 加股東權益規模百分位 40%。

### 6.2 價值型

```text
品質25% + 月營收成長5% + 累計營收成長10% + 估值30%
+ 技術15% + 法人4% + 市場4% + 時事2% + 流動性5%
```

納入條件：EPS 為正、本益比小於 15、股價淨值比小於 2、負債率不高於 70%。

### 6.3 成長型

```text
品質20% + 月營收成長20% + 累計營收成長10% + 估值10%
+ 技術20% + 法人5% + 市場5% + 時事2% + 流動性8%
```

納入條件：EPS 為正、月營收年增至少 20%、ROE 為正。

### 6.4 品質型

```text
品質35% + 月營收成長7% + 累計營收成長10% + 估值20%
+ 技術15% + 法人3% + 市場3% + 時事2% + 流動性5%
```

納入條件：EPS 為正、ROE 至少 10%、毛利率為正、負債率不高於 60%。

## 7. 法人影響與炒作風險

法人影響程度另外計算，不直接取代基本分數：

- 5 日價格上漲至少 8%：增加影響點數；
- 外資與投信 5 日淨買超占成交量至少 5% 或 10%：增加影響點數；
- 當日成交金額相對 20 日均值至少 1.8 倍：增加影響點數；
- 若基本面偏弱或估值昂貴但上述籌碼訊號很強：提高炒作風險。

系統會顯示法人影響與炒作風險為低、中或高，提醒使用者區分基本面改善與資金推動。

## 8. 已知限制

- 前 100 檔仍有部分資料受 FinMind 公開額度限制；
- 多數股票歷史價格尚不足 500 日，暫時不使用自身歷史估值；
- 金融業仍缺少淨利差、逾放比與資本適足率；
- 尚未建立無未來資料偏誤的完整歷史回測；
- 重大訊息文字判斷只能作小幅輔助，不代表事件的最終財務影響；
- 百分位分數會隨候選股票範圍及資料完整度改變。

## 9. 解讀原則

正確使用順序應為：

1. 確認資料是否完整；
2. 查看使用的產業模型；
3. 查看各構面分數，而非只看總分；
4. 閱讀失效條件與景氣循環風險；
5. 確認目前估值及歷史估值資料是否可靠；
6. 再進行公司、產業與風險研究。

本文件描述目前程式實作，未來每次調整權重、資料口徑或門檻時應同步更新版本與日期。
